# simulacion-kalman-python
Este repositorio va a funcionar para poder entender/probar/simular el filtro de kalman lineal.

## Idea
Simular lecturas ruidosas de los sensores (barometro y acelerometro)
y poder analizar como predecimos el apogeo. 
1. Solo con los sensores crudos. 
2. Usando un kalman lineal con un modelo simple (tiro vertical) para ver si logramos mejorar la prediccion del estado del vector y del apogeo
